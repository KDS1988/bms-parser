# BMS Event Watcher

Google Apps Script, который следит за bms-api.vsporte.ru:
- при новом/изменённом мероприятии шлёт уведомление в Telegram-группу «отдел назначений»
- пишет данные на листы «Новые мероприятия» и «Тех блок»
- автоматически размещает мероприятия на «доске» (по месяцам, по дням, по матчам)
- раз в сутки собирает «График персонала» — занятость сотрудников по амплуа и датам

## Структура

- `Code.gs` — весь код проекта
- `appsscript.json` — манифест Apps Script (таймзона, версия рантайма)
- `.clasp.json.example` — шаблон конфига для [clasp](https://github.com/google/clasp)

## Установка с нуля

### 1. Инструменты

```bash
npm install -g @google/clasp
clasp login
```

Авторизуйся тем же Google-аккаунтом, где таблица.

### 2. Привязка к существующему Apps Script проекту

Если проект уже создан (Extensions -> Apps Script в таблице):
1. Apps Script -> ⚙️ Project Settings -> скопируй **Script ID**
2. В этой папке:
   ```bash
   cp .clasp.json.example .clasp.json
   ```
   и вставь свой Script ID в `.clasp.json`

Если проекта ещё нет — `clasp create --type sheets --title "BMS Event Watcher" --parentId <ID_ТАБЛИЦЫ>`.

### 3. Секреты — ОБЯЗАТЕЛЬНО перед первым запуском

Токен Telegram-бота, номер телефона и chat_id **не хранятся в коде** (чтобы не улетели в git). Их нужно один раз задать через Script Properties:

1. `clasp push` (см. ниже) — зальёт код
2. Открой проект: `clasp open`
3. Найди функцию `setupSecrets()` в редакторе, впиши свои значения вместо плейсхолдеров:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather
   - `TELEGRAM_CHAT_ID` — id группы/чата в Telegram (отрицательное число для группы)
   - `BMS_PHONE` — телефон для входа в BMS, без `+`
4. Выполни `setupSecrets()` **один раз** (▶ Run) — сохранит значения в Script Properties
5. **Убери свои значения обратно на плейсхолдеры** в `Code.gs` у себя локально и закоммить чистую версию — сами секреты уже сохранены в Apps Script, в коде они больше не нужны

Дальше при каждом обновлении `clasp push` эти секреты не трогает — они живут отдельно от кода.

### 4. Вход в BMS

Меню таблицы **BMS -> 🔑 Войти в BMS** — введи номер телефона (или он подставится сам из секретов) и код, который придёт в Telegram-бот `@vsporte_bms_bot`.

### 5. Триггеры (ставятся вручную, clasp их не переносит)

В Apps Script -> ⏰ Triggers -> **+ Add Trigger**:

| Функция | Тип | Когда |
|---|---|---|
| `doPoll` | Time-driven | Every 5-10 minutes |
| `dailyStaffScheduleFetch` | Time-driven, Day timer | 9:00-10:00 |

`onEdit` ставить не нужно — это простой триггер, Apps Script подхватывает его сам по имени функции.

## Рабочий процесс обновления кода

```bash
# внести правки в Code.gs
git add . && git commit -m "что поменялось"
clasp push
```

`clasp push` заливает файл целиком — исключает ситуацию, когда в редакторе Apps Script остаётся смесь старой и новой версии кода после ручного copy-paste.

Полезно: `clasp push -w` — следит за изменениями файла и заливает автоматически при каждом сохранении.
